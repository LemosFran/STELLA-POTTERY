# Stella Pottery

A responsive, buildless website using the supplied Stella fonts, photography, and brand assets.

Open `dist/index.html` in a browser. No installation or build step is needed.

For Vercel, keep Root Directory at the repository root (`./`). The root
`vercel.json` configures static hosting from `dist`, with no install or build
step. Push this configuration and redeploy to apply it.

Features include anchor navigation, a mobile menu, a horizontally scrolling artwork gallery, accessible artwork dialogs, expandable process steps, and reduced-motion support.

The Sites identity is saved in `.openai/hosting.json`. Publishing was attempted but blocked because the local environment could not resolve `git.chatgpt-team.site`. The source has not been pushed or deployed. Reuse the saved project ID when publishing later.

Validation: JavaScript syntax and local HTML/CSS asset references passed. Browser visual testing remains incomplete.
